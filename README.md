# GitHub App Manifest Playground

An interactive tool for creating GitHub Apps using the [manifest flow](https://docs.github.com/en/developers/apps/building-github-apps/creating-a-github-app-from-a-manifest).

This project uses [Vite](https://vite.dev) + React + TypeScript.

## Available Scripts

### `npm run dev`

Runs the app in development mode.\
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

The page will reload when you make changes.\
You will also see any errors in the console.

### `npm run build`

Builds the app for production to the `dist` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include hashes.\
Your app is ready to be deployed!

### `npm run preview`

Locally preview the production build before deploying.

### `npm run deploy`

Builds the app and deploys it to GitHub Pages.
